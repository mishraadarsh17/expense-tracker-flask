* Expense Tracker

A Flask-based Expense Tracker web application.

## Features

- User Registration & Login
- Password Hashing
- Session Management
- Add Expense
- Edit Expense
- Delete Expense
- Search Expenses
- Category Filter
- Date Filter
- Pagination
- Profile Management
- Profile Photo Upload
- CSV Export
- Dashboard Statistics

## Tech Stack

- Python
- Flask
- SQLite
- Bootstrap
- HTML/CSS
- Git & GitHub
- Render
